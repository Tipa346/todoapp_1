TodoApp
    Windows Forms приложение для управления списком задач.
Возможности
- Добавление, удаление и переименование задач.
- Установка приоритета от 1 до 5, где 1 — самый высокий.
- Установка даты окончания задачи.
- Отметка задач как выполненных.
- Поиск по названию.
- Фильтрация по статусу и дате окончания.
- Сортировка по срочности, приоритету, дате и названию.
- Автоматическая окраска задач от зелёного до красного в зависимости от близости даты окончания.
- Автоматическое сохранение задач в `todos.json`.
Проект использует C# и Windows Forms.
